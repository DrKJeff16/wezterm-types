### `wezterm-theme-rotator`

You can import type annotations for [`koh-sh/wezterm-theme-rotator`](https://github.com/koh-sh/wezterm-theme-rotator) as shown below:

```lua
local theme_rotator = wezterm.plugin.require("https://github.com/koh-sh/wezterm-theme-rotator") --[[@as ThemeRotator]]
```
